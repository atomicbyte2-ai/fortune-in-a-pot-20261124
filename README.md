One line: a fortune-cookie fortune for the houseplant on the windowsill.

> Your roots are plotting an escape, but the sun talked them into one more summer on this sill.

## Run

```sh
node main.ts
```

This validates the line (one line, 93 characters, within the 120-character limit, and clearly about the plant) and writes it to `entry.txt`. No network, no input, no dependencies.
